# Learning Journal

This repository contains the final version of the Learning Journal project. It is designed to help users document their learning journey, track progress, and reflect on their experiences.

## Features

- Add, edit, and delete journal entries.
- Organize entries by date or category.
- Search functionality to quickly find specific entries.
- User-friendly interface for seamless navigation.

## Installation
If you don't have Node.js installed, download and install it from [Node.js official website](https://nodejs.org/).
1. Clone the repository:
    ```bash
    git clone https://github.com/Fahad-Al-Maashani/Quizzy_Agent_AI_Learning.git
    ```
2. Navigate to the project directory:
    ```bash
    cd learning-journal-final3
    ```
3. Install dependencies:
    ```bash
    npm install
    ```

## Usage

1. Start the development server:
    ```bash
    npm start
    ```
2. Open your browser and navigate to `http://localhost:3000`.

## Technologies Used

- **Frontend**: React, CSS
- **Backend**: Node.js, Express
- **Database**: MongoDB
